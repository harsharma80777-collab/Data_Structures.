//Number Hashing

   
#include <bits/stdc++.h>
using namespace std;

int main(){
    int n;
    cin >> n;
    int arr[n];
    for (int i = 0 ; i<n ; i++){  
        cin >> arr[i];
    }
    // precompute
     int hash[13] = {0};  // we can't just say for hash[n] otherwise it would give rubbish/garbage value for not given number in the array
     for (int i=0; i< n ;i++){
         hash[arr[i]] +=1;
     }
     //queries
     int q;
     cin >> q;
     while (q--){
         int number ;
         cin >> number;
         //fetch
         cout << hash[number] << endl;
     }
    return 0;
}

//Character Hashing
#include <bits/stdc++.h>
using namespace std;

int main(){
    string s;
    cin >> s;
    //precomputing
    int hash[26]={0};
    for (int i = 0; i< s.size(); i++){
        hash[s[i] - 'a']++; //indexing of the characters in the given hash array (eg. 0 to a , 1 to b and so on)
    }
    //queries

    int q;
     cin >> q;
     while (q--){
         char c;
         cin >> c;
         
         // fetch 
         cout << hash[c - 'a'] << endl;  // c - 'a' becoz for the index we have to go for character - first letter i.e. a
     }
    return 0;
}


In this we used hash of 26 but for there existing 256 characters so we would be using hash[256] and in that case we won't need any - (subtraction) of those number or a char.

As we can't hash numbers more than 10e7; so for that we would be using STL and unordered map in C++ or HashMap in Java.
For this we have to declare a Key(element) and Value(frequency) 
Map is used to store the elements in sorted order of keys while unordered as the name sugget does not follow any specificity in order.
So Why do we have to use Hashing  using map instead of the array hashing?
The difference considering the array: [1, 2, 3, 1, 3, 2, 12]. Here, the maximum element of the array is 12. So, if we apply array hashing, we need an array of size 13. While the map would just neend those 4 blocks (1,2,3,12).
Note: If we want to fetch the value of a key that does not exist in the map, the map will always return 0 in C++ and null in Java.

So we would use mapping that would again reduce the time and space complexity of that code
