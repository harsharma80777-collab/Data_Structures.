# Data Structures & Algorithms Practice

A collection of foundational programming concepts, algorithmic paradigms, and data structure implementations written primarily in C++. This repository serves as a personal log for mastering core problem-solving techniques and competitive programming essentials.

---

## Repository Structure

| File / Directory | Topic | Description |
| :--- | :--- | :--- |
| `Conditionals.cpp` | Flow Control | Core decision-making logic (`if`, `else if`, `switch-case`) |
| `Loops.cpp` | Iteration | Iterative constructs (`for`, `while`, `do-while`) and iteration state tracking |
| `Pattern.cpp` | Logic Building | Nested loops for printing coordinate patterns, matrices, and pyramid structures |
| `SimpleSorting.txt` | Basic Sorting | Reference notes and implementations of elementary sorts (Bubble, Selection, Insertion) |
| `ModernSorting.txt` | Advanced Sorting | Divide-and-conquer and efficient sorting algorithms (Merge Sort, Quick Sort) |
| `Hashing/` | Hashing Techniques | Frequency counting, hash maps, hash sets, and collision handling techniques |

---

## How to Compile and Run (C++)

Compile and run individual C++ files using standard `g++` via the terminal:

```bash
# Compile
g++ -O2 Conditionals.cpp -o run_code

# Execute
./run_code
